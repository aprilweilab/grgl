Tutorials
==========

These tutorials show how to use ``pygrgl``, ``grapp``, and ``grg_pheno_sim`` to perform data analysis,
filtering, GWAS, and other operations. The tutorials are based on Jupyter notebooks that can be
downloaded from `here <https://github.com/aprilweilab/grgl/tree/main/doc/tutorials/notebooks>`_,
if you want to run them locally.
